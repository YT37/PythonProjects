# MediaImporter
- This project imports TV Shows & Movies into Media Server and renames them as required by Plex/Jellyfin/Emby.

# Requirements
- Python 3.6 or up
- BeutifulSoup4
- Requests

# Instructions 
- Make sure to change Path in MediaImporter.py (Lines: 9-10)

- **Windows, Mac and Linux**
  ``` 
  pip install -r requirements.txt
  ```
- **Windows**
  ```
  python MediaImporter.py
  ```
- **Mac or Linux**
  ```
  python3 MediaImporter.py
  ```
